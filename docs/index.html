The Problem

Autonomous agents are powerful.
Ungoverned agents are dangerous.

payments

Budget Overruns

A single agent loop can exhaust thousands in GPU compute with no built-in spending limits or solvency checks.

sync_problem

Infinite Loops

Agents retry identical failed operations indefinitely — each cycle burning tokens and time without progress.

visibility_off

Zero Audit Trail

Black-box execution with no flight recorder, no state machine, and no mechanism to replay what happened.

psychology_alt

No Learning

Agents repeat identical mistakes across sessions — no shared memory, no friction analysis, no self-improvement.

The Solution

One install. Complete governance.

Six deterministic modules that enforce cost limits, policy-as-code, audit trails, and self-improvement. Zero LLM dependencies in the core.

shield

Cost Guard

Real-time solvency gating. Blocks execution when projected spend exceeds budget. Per-tier rate cards with configurable thresholds.

ag-os check 1.0 --tier gpu_a100
gavel

The Constitution

Nine governance rules enforced at every state transition. Policy-as-code defined in Markdown. Extensible by design.

.agent/rules/08-economic-safety.md
flight

Flight Recorder

Deterministic state machine with complete audit trail. SQLite WAL-backed. Every operation tracked end-to-end with replay capability.

ag-os status
lightbulb

DreamEngine

Self-improvement loop. Scans friction logs, identifies failure patterns, and synthesizes governance patches automatically.

ag-os dream --apply
hub

Provider Registry

Six swappable abstraction surfaces — secrets, issues, cost, state, telemetry, policy. Works offline. Scales to cloud.

providers: { cost: gcp, state: redis }
smart_toy

MCP Server

Exposes governance as Model Context Protocol tools. Any MCP-compatible agent gets governance built-in.

ag-os serve

Governing a production multi-agent pipeline

The System

What's Being Governed

A multi-tenant content pipeline with 7 specialized agents, each with sub-agent decomposition. Deployed with per-tenant adapters across regional endpoints.

  • account_tree 7 agents, 15+ sub-agents
  • language 5 regional tenants (IL, US, MX, ES, PT)
  • memory GPU-accelerated inference endpoints
AG-OS Modules Active

Governance Applied

Four AG-OS modules govern this pipeline end-to-end: cost enforcement per operation, policy evaluation at every state transition, full execution tracing, and automated self-improvement.

  • shield Cost Guard — per-operation solvency
  • gavel Constitution — 9 rules enforced
  • flight Flight Recorder — full trace
  • lightbulb DreamEngine — patch synthesis
