The Problem

Autonomous agents are powerful.
Ungoverned agents are dangerous.

💸

Budget Overruns

A single agent loop can burn through thousands in GPU compute before anyone notices. No built-in spending limits.

🔄

Infinite Loops

Agents retry failed tasks endlessly — 5, 10, 20 cycles of identical errors — each costing time and money.

🚫

No Audit Trail

When things break in production, there's no flight recorder. No state machine. No way to replay what happened.

🧠

No Learning

Agents make the same mistakes repeatedly. No memory of past failures, no mechanism to improve governance over time.

The Solution

One install. Complete governance.

Antigravity OS wraps any AI agent pipeline with an integrated governance layer — cost enforcement, policy evaluation, state tracking, and self-improvement. All deterministic. Zero LLM dependencies in the core.

🛡️

Cost Guard

Real-time solvency gating. Block execution when projected spend exceeds budget. Per-tier rate cards.

ag-os check 1.0 --tier gpu_a100
📜

The Constitution

9 governance rules enforced at every state transition. Policy-as-code in Markdown. Extensible.

.agent/rules/08-economic-safety.md
✈️

Flight Recorder

Deterministic state machine with full audit trail. SQLite-backed. Every operation tracked end-to-end.

ag-os status
💡

DreamEngine

Self-improvement loop. Scans friction logs, detects patterns, synthesizes governance patches. Agents that learn.

ag-os dream --apply
🔌

Provider Registry

6 swappable surfaces — secrets, issues, cost, state, telemetry, policy. Works offline, scales to cloud.

providers: { cost: gcp, state: redis }
🤖

MCP Server

Expose governance as MCP tools. Any MCP-compatible agent (Claude, Cursor) gets governance built-in.

ag-os serve
