## How to add your organization

Add a row to the appropriate table with:
- Organization name
- Brief description of use case
- Link to public reference (optional)

If you'd rather not be public yet, drop a line via
[GitHub Discussions](https://github.com/Manzela/Antigravity-OS/discussions)
(or via [private vulnerability reporting](https://github.com/Manzela/Antigravity-OS/security/advisories/new)
if confidentiality matters) and we'll keep your usage off the public list
while still updating the maintainer's roadmap with your needs.
