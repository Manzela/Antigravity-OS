# Agent Skills Registry

- **plan_feature**: Generate markdown implementation plans.
- **read_contract**: Fetch API schemas from `docs/API_Contract.md`.
- **run_tests**: Execute test suite via `pytest`.
- **snapshot_ui**: Capture screenshots of the UI.
- **scan_dependencies**: Check for CVEs (Sentinel).
- **check_solvency**: Run Cost Guard validation (Rule 08) via `ag-os check`.
- **evaluate_governance**: Run policy evaluation via the Rules Engine.
- **record_state**: Track operation state via the Flight Recorder.
